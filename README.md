# task_scheduler
This is a personal project. I implement a task scheduler using the round-robin-based algorithms. It has four tasks running alternatively with a timeslice of one second. The project uses a low-level coding style that doesn't use any library from HAL. From this project, I gained new knowledge about task scheduling, CPU register management, and interrupt-related concepts.
